## 1. 傳統求值法

### 1.1 先想清楚資料長什麼樣

題目說係數是 $a_0, a_1, \dots, a_n$。

🤔 如果多項式是 $n$ 次，係數陣列的長度是多少？是 $n$ 還是 $n+1$？
（這是最常見的 off-by-one 錯誤來源，請寫在函式旁邊的註解裡提醒自己。）

🤔 你要用 C 風格陣列還是 `std::vector<double>`？題目第二題給的範本用的是 `std::vector`，現在就選它，之後改成範本會比較輕鬆。

### 1.2 兩種寫法

題目允許兩種方式算 $a_k x^k$：

- **寫法 A**：呼叫 `std::pow(x, k)`
- **寫法 B**：自己寫一個迴圈，把 $x$ 乘 $k$ 次

🤔 寫法 B 要用幾層迴圈？外層負責什麼、內層負責什麼？

🤔 算第 $k$ 項 $a_k x^k$，寫法 B 總共要做幾次乘法？（提示：$x^k$ 本身要乘幾次？再乘上 $a_k$ 呢？$k=0$ 時呢？）

🤔 把每一項的乘法次數從 $k=0$ 加到 $k=n$，你能自己推出 $\frac{n(n+1)}{2}$ 嗎？

> 💡 **建議兩種寫法都做**。寫法 B 才能在 [03-big-o.md](03-big-o.md) 精確地「數」乘法次數，因為你看不到 `std::pow` 裡面做了幾次乘法。

## 3. 正確性與一致性驗證：$\sin(\pi/4)$ 與 $\cos(\pi/4)$

### 3.1 把級數翻譯成「係數陣列」

$$S_n = \sum_{k=0}^{n} (-1)^k \frac{x^{2k+1}}{(2k+1)!}$$

🤔 $S_n$ 是幾次多項式？所以係數陣列長度是多少？

🤔 以 $S_1 = x - \frac{x^3}{6}$ 為例，寫出完整的係數陣列（包含那些為 0 的係數）。哪些位置是 0？

🤔 對 $C_n$（cos）做同樣的事。

### 3.2 怎麼算 $(2k+1)!$？

🤔 如果每個係數都從頭算一次階乘，$k=8$ 時要乘幾次？有沒有辦法從**前一個係數**直接得到**下一個係數**？

（試著寫出 $\frac{1}{(2k+1)!}$ 和 $\frac{1}{(2k-1)!}$ 的比值。）

這就是題目提示說的「係數的產生也可以考量成巢狀嵌套」。

### 3.3 進階想法（可選）

$S_n$ 一半的係數都是 0，Horner 法會白白乘很多次。

🤔 試著把 $\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots$ 提出一個 $x$，剩下的部分是不是變成 $x^2$ 的多項式？如果令 $y = x^2$，能不能對 $y$ 做 Horner？

🤔 更進一步：
$$x\left(1 - \frac{x^2}{2\cdot3}\left(1 - \frac{x^2}{4\cdot5}\left(1 - \cdots\right)\right)\right)$$
這個寫法還需要事先算出階乘嗎？

這是加分的思考，先把基本版做出來再說。

### 3.4 輸出設計

🤔 你的表格要有哪些欄位？建議至少包含：

- $n$
- 傳統法的值、Horner 的值
- 兩者的差（**一致性**：兩種算法彼此差多少）
- 各自與 `std::sin(M_PI/4)` 的差（**正確性**：離真值多遠）

🤔 $n$ 從 1 增加到 8，誤差應該呈現什麼趨勢？到某個 $n$ 之後，誤差還會繼續變小嗎？為什麼會停住？（提示：`double` 大約有幾位有效數字？）

🤔 傳統法和 Horner 的差，是 0 嗎？如果不是 0，數量級大約多少？這和題目提示「加減乘的順序不同，浮點誤差不盡相同」有什麼關係？

## 4. 浮點捨入誤差累積

$$P(x) = \sum_{k=0}^{n} C^n_k \, x^{n-k} (-1)^k$$

### 4.1 先別急著寫程式

🤔 **這是整份作業最重要的觀察之一**：這個式子是不是很眼熟？回想二項式定理 $(a+b)^n = \sum C^n_k a^{n-k} b^k$。$P(x)$ 其實等於什麼？

🤔 如果你看出來了，那 $P(1.1)$ 和 $P(1.01)$ 的**精確值**是多少？這個精確值就是你的「標準答案」，用它來判斷傳統法和 Horner 誰比較準。

### 4.2 係數與陣列方向

🤔 注意這裡是 $x^{n-k}$，不是 $x^k$。如果你的求值函式約定「`a[k]` 是 $x^k$ 的係數」，那 $x^j$ 的係數是多少？（令 $j = n-k$ 換一下變數。）

🤔 $C^n_k$ 怎麼算？可以用巴斯卡三角形，也可以用 $C^n_k$ 和 $C^n_{k-1}$ 的比值遞推。$n=20$ 時最大的 $C^{20}_{10}$ 有多大？用 `int` 存會溢位嗎？用 `double` 存是精確的嗎？

### 4.3 觀察與思考

🤔 $n$ 從 1 到 20，兩種方法的**相對誤差**（誤差 ÷ 精確值）怎麼變化？$x=1.01$ 和 $x=1.1$ 哪一個比較慘？

🤔 想想看：多項式的各項是很大的正數和很大的負數交錯相加，最後結果卻非常小。這種「大數相減得到小數」會發生什麼事？（關鍵字：**catastrophic cancellation**）

🤔 **題目的提問**：Horner 減少了運算次數，是否也減少了誤差？請**根據你的實驗數據**回答，不要只憑直覺。如果數據顯示 Horner 沒有明顯比較好，也是一個有價值的發現，請試著解釋原因。

## 5. 問題延伸

### 5.1 效率量測（`<chrono>`）

🤔 只算一次 $n=8$ 的多項式，量得到時間差嗎？要怎麼讓時間「大到量得出來」？（提示：$n$ 要多大？要重複幾次？）

🤔 編譯器很聰明，如果你算出來的結果從來沒被使用，它可能整段程式都不執行。你要怎麼確保計算真的有發生？

🤔 量到的時間比值，和理論的乘法次數比值 $\frac{n(n+1)/2}{n}$ 接近嗎？如果不接近，可能是哪些因素造成的？（`std::pow` 真的是一個一個乘嗎？）

### 5.2 溢位（overflow）

🤔 `double` 能表示的最大值大約是多少？（查 `std::numeric_limits<double>::max()`。）

🤔 設 $x = 10^{10}$，$n = 40$，`std::pow(x, n)` 會變成什麼？

🤔 關鍵思考：傳統法先算 $x^n$ **再**乘 $a_n$；Horner 從 $a_n$ 開始**逐步**乘 $x$。如果 $a_n$ 非常非常小（例如 $10^{-300}$），兩種方法的中間值分別多大？誰先爆掉？

🤔 請設計一組 $(a_k, x, n)$，讓 $P(x)$ 的真實值在 `double` 範圍內，但傳統法得到 `inf`，Horner 卻算得出來。
