## 1. 先確認你懂定義

> $`f(n) = O(g(n))`$：存在 $`M > 0`$ 和 $`n_0`$，使得對所有 $`n \ge n_0`$，$`|f(n)| \le M\,|g(n)|`$。

**試試看：** 題目說 $`\frac{n(n+1)}{2} = O(n^2)`$，取 $`M=1`$、$`n_0=1`$。請驗證 $`\frac{n(n+1)}{2} \le n^2`$ 對所有 $`n \ge 1`$ 都成立。

<details>
<summary>答案</summary>

```math
\frac{n(n+1)}{2} \le n^2 \iff n+1 \le 2n \iff n \ge 1
```

成立。

</details>

**想一想：** 那 $`\frac{n(n+1)}{2} = O(n)`$ 嗎？試著找 $`M`$；找不到的話，說明為什麼。

<details>
<summary>答案</summary>

不是。需要 $`\frac{n(n+1)}{2} \le Mn`$，也就是 $`\frac{n+1}{2} \le M`$ 對所有夠大的 $`n`$ 成立。但 $`\frac{n+1}{2}`$ 會無限變大，不論 $`M`$ 取多大，總有 $`n`$ 超過它。

</details>

**想一想：** Horner 的 $`n`$ 次乘法是 $`O(n)`$，那它是不是也是 $`O(n^2)`$？

<details>
<summary>答案</summary>

**是**。取 $`M=1`$、$`n_0=1`$，$`n \le n^2`$ 成立。$`O`$ 只是「上界」，$`O(n^2)`$ 是對的，只是不夠緊。我們說 Horner 是 $`O(n)`$，是因為那是最緊的上界。

</details>

## 2. 在程式裡「數」運算次數

### 2.1 計數器放哪裡？

**想一想：** 傳統法為什麼不能用 `std::pow` 來數乘法次數？

<details>
<summary>答案</summary>

`std::pow` 是黑盒子，你看不到它內部做了幾次乘法（而且它通常不是用連乘實作的）。必須用第一題的「寫法 B」自己寫迴圈乘，每一個 `*` 都看得見。

</details>

**想一想：** 每一個 `*` 和 `+` 都要對應一個計數器加 1。有沒有哪個乘法藏在不起眼的地方？迴圈變數的 `++k` 算不算「加法」？

<details>
<summary>答案</summary>

- Horner 的 `result * x`、傳統法內層迴圈的連乘，都要算。
- 傳統法加總時，如果總和從 0 開始、加了 $`n+1`$ 項，就是 $`n+1`$ 次加法；從 $`a_0`$ 開始，才是 $`n`$ 次。差這一次是常見的落差。
- `++k`、`k >= 0` 這類迴圈控制是**整數**運算，不屬於「多項式求值的浮點運算」，通常不算。請在報告中寫清楚你的約定。

</details>

### 2.2 計數器怎麼傳出來？

**想一想：** 全域變數、參考（reference）參數、回傳一個 `struct`，三種做法哪種最不容易出錯？

<details>
<summary>答案</summary>

- **全域變數**：最簡單，但每次測量前都要記得歸零，忘了就會累加到上一次的次數。
- **參考參數**：函式簽名清楚，但呼叫端仍要自己歸零。
- **回傳 `struct`**（裡面放「值、乘法次數、加法次數」）：每次呼叫都得到全新的計數，沒有隱藏狀態，**最不容易出錯**。

</details>

### 2.3 計數器的型別

**試試看：** $`n = 10000`$ 時，$`\frac{n(n+1)}{2}`$ 是多少？`int` 存得下嗎？$`n = 100000`$ 呢？

<details>
<summary>答案</summary>

- $`n = 10000`$：$`50{,}005{,}000`$，`int`（上限約 $`2.1\times10^{9}`$）存得下。
- $`n = 100000`$：$`5{,}000{,}050{,}000`$，超過 `int` 上限，會溢位。

計數器用 `long long` 比較保險。

</details>

### 2.4 係數從哪來？

**想一想：** 這一節只關心「次數」。係數全部給 1.0 可以嗎？$`x`$ 該取什麼值，才不會在 $`n=10000`$ 時溢位或變成 0？

<details>
<summary>答案</summary>

可以，次數和係數的值無關。$`x`$ 取 1.0（或非常接近 1 的數），$`x^{10000}`$ 才不會變成 `inf` 或 0。若 $`x = 2`$，$`2^{10000}`$ 會溢位，傳統法和 Horner 都會出現 `inf`；計數本身不受影響，但印出來的值沒有意義。

</details>

## 3. 驗證與理論吻合

**試試看：** 把實測結果填進這張表。

| $`n`$ | 傳統法乘法（實測） | $`\frac{n(n+1)}{2}`$ | Horner 乘法（實測） | $`n`$ |
|-------|-------------------|----------------------|--------------------|-------|
| 10 | | | | |
| 100 | | | | |
| 1000 | | | | |
| 10000 | | | | |

<details>
<summary>答案</summary>

理論值（你的實測值應該**完全相同**）：

| $`n`$ | $`\frac{n(n+1)}{2}`$ | $`n`$ |
|-------|----------------------|-------|
| 10 | 55 | 10 |
| 100 | 5050 | 100 |
| 1000 | 500500 | 1000 |
| 10000 | 50005000 | 10000 |

</details>

**想一想：** 如果實測值和公式差一點點（例如差 $`n+1`$ 或差 1），要怎麼辦？

<details>
<summary>答案</summary>

**不要調公式來湊**，回去檢查程式：

- 你的 $`n`$ 是「次數」還是「係數個數」？兩者差 1。
- 傳統法每項是不是「從 1 開始乘 $`k`$ 次再乘 $`a_k`$」？這樣總數會是 $`\frac{(n+1)(n+2)}{2}`$。
- Horner 的 `result` 是不是從 0 開始？這樣會多 1 次乘法。

這種差 1 的 bug 正是這個練習想讓你抓到的。

</details>

## 4. n 翻倍的代價

**試試看：** 用代數算 $`\dfrac{f(2n)}{f(n)}`$，其中 $`f(n) = \frac{n(n+1)}{2}`$。當 $`n \to \infty`$ 時趨近多少？對 Horner 的 $`f(n) = n`$ 呢？

<details>
<summary>答案</summary>

```math
\frac{f(2n)}{f(n)} = \frac{2n(2n+1)/2}{n(n+1)/2} = \frac{2(2n+1)}{n+1} \;\longrightarrow\; 4
```

Horner：$`\frac{2n}{n} = 2`$，恰好 2 倍。

</details>

**想一想：** 用程式驗證 $`n = 10 \to 20`$、$`100 \to 200`$、$`1000 \to 2000`$ 的比值。$`n`$ 小的時候比值剛好是 4 嗎？為什麼 $`n`$ 越大越接近 4？

<details>
<summary>答案</summary>

| $`n \to 2n`$ | 比值 $`\frac{2(2n+1)}{n+1}`$ |
|--------------|------------------------------|
| 10 → 20 | $`42/11 \approx 3.818`$ |
| 100 → 200 | $`402/101 \approx 3.980`$ |
| 1000 → 2000 | $`4002/1001 \approx 3.998`$ |

$`\frac{n(n+1)}{2} = \frac{n^2}{2} + \frac{n}{2}`$。$`n`$ 小的時候，低次項 $`\frac{n}{2}`$ 還佔有份量；$`n`$ 越大，$`n^2`$ 越主導，比值就越接近 $`2^2 = 4`$。這也是 Big-O 只看最高次項的原因。

</details>

## 5. 問題延伸

### 5.1 和 O(n³) 比較

**試試看：** 列出 $`n = 10, 100, 1000`$ 時，$`n`$、$`n^2`$、$`n^3`$ 的值。

<details>
<summary>答案</summary>

| $`n`$ | $`n`$（Horner） | $`n^2`$（傳統法） | $`n^3`$（高斯消去） |
|-------|-----------------|-------------------|---------------------|
| 10 | 10 | 100 | 1000 |
| 100 | 100 | $`10^{4}`$ | $`10^{6}`$ |
| 1000 | 1000 | $`10^{6}`$ | $`10^{9}`$ |

</details>

**想一想：** 多項式的「$`n`$」是什麼？高斯消去法的「$`n`$」是什麼？兩個問題的「輸入資料量」分別有多少？用「每個輸入資料平均被處理了幾次」的角度說明為什麼成長速度差這麼多。

<details>
<summary>答案</summary>

- 多項式：$`n`$ 是**次數**，輸入是 $`n+1`$ 個係數。Horner 對每個係數只做 1 乘 1 加，每筆資料平均處理 $`O(1)`$ 次。
- 線性方程組：$`n`$ 是**矩陣維度**，輸入是 $`n^2 + n`$ 個數字。總運算 $`O(n^3)`$ 除以資料量 $`O(n^2)`$，每筆資料平均被處理 $`O(n)`$ 次（每一列都要被前面所有的主元列消去一次）。

所以同樣叫「$`n`$」，背後的資料量就差了一個次方；若改用資料量 $`N`$ 來表示，Horner 是 $`O(N)`$，高斯消去是 $`O(N^{1.5})`$。

</details>

### 5.2 O(n log n) 落在哪裡？

**想一想：** $`\log n`$ 和 $`1`$ 比、和 $`n`$ 比，哪個大？所以 $`n \log n`$ 和 $`n`$、$`n^2`$ 的大小關係是？

<details>
<summary>答案</summary>

當 $`n > 2`$ 時，$`1 < \log_2 n < n`$。兩邊同乘 $`n`$：

```math
n < n\log_2 n < n^2
```

所以 $`O(n\log n)`$ 確實落在 Horner 與傳統法之間，而且比較靠近 $`O(n)`$。

</details>

**試試看：** 用程式印出 $`n = 2^1, 2^2, \ldots, 2^{20}`$ 時 $`n`$、$`n\log_2 n`$、$`n^2`$ 的值，再畫成三條曲線。$`y`$ 軸用一般刻度時，$`n^2`$ 會讓其他兩條線變成什麼樣子？改用對數刻度呢？

<details>
<summary>答案</summary>

$`n = 2^{20} \approx 10^{6}`$ 時：$`n \approx 1.0\times10^{6}`$、$`n\log_2 n \approx 2.1\times10^{7}`$、$`n^2 \approx 1.1\times10^{12}`$。

一般刻度下，$`n^2`$ 大到讓另外兩條線幾乎貼在 $`x`$ 軸上，看不出差別。改用**雙對數刻度**（log-log）：$`n`$ 和 $`n^2`$ 變成斜率 1 與 2 的直線，$`n\log n`$ 則是斜率略大於 1、稍微往上彎的線，三者的差距一目了然。

可以把資料輸出成 CSV，用 Excel、Google Sheets 或 Python 畫圖。

</details>
