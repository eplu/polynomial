## 0. 先確認你懂定義

> $f(n) = O(g(n))$：存在 $M > 0$ 和 $n_0$，使得對所有 $n \ge n_0$，$|f(n)| \le M\,|g(n)|$。

🤔 題目說 $\frac{n(n+1)}{2} = O(n^2)$，取 $M=1$、$n_0=1$。請你自己驗證：$\frac{n(n+1)}{2} \le n^2$ 對所有 $n \ge 1$ 都成立嗎？（把不等式整理一下。）

🤔 那 $\frac{n(n+1)}{2} = O(n)$ 嗎？試著找 $M$，找不到的話，說明為什麼找不到。

🤔 Horner 的 $n$ 次乘法是 $O(n)$，那它是不是也是 $O(n^2)$？（依照定義回答，答案可能和直覺不同。）

## 1. 在程式裡「數」運算次數

### 1.1 計數器放哪裡？

🤔 傳統法要用「寫法 B」（自己寫迴圈乘），為什麼不能用 `std::pow`？

🤔 在你的函式裡，每一個 `*` 和 `+` 出現的位置，都要對應一個計數器加 1。仔細看你的程式：

- 有沒有哪個乘法藏在不起眼的地方？（例如 `result * x` 和 `a[k] * 冪次` 都要算。）
- 迴圈變數的 `++k` 算不算「加法」？（題目要數的是**浮點數**的運算，請想清楚並在報告中說明你的約定。）

### 1.2 計數器怎麼傳出來？

🤔 有幾種做法，各有優缺點：

- 全域變數：最簡單，但每次測量前要記得歸零。忘了會怎樣？
- 用參考（reference）參數把計數器傳進函式
- 讓函式回傳一個 `struct`，裡面同時放「值」、「乘法次數」、「加法次數」

選一種，並想想：哪種方式最不容易出錯？

### 1.3 計數器的型別

🤔 $n = 10000$ 時，$\frac{n(n+1)}{2}$ 是多少？`int` 存得下嗎？如果 $n = 100000$ 呢？計數器應該用什麼型別？

### 1.4 係數從哪來？

🤔 這一節只關心「次數」，不關心「值」。係數隨便給（例如全部是 1.0）可以嗎？$x$ 應該取什麼值，才不會在 $n=10000$ 時溢位或變成 0？（想一下第一題的溢位延伸題。）

## 2. 驗證與理論吻合

🤔 製作一張表：

| $n$ | 傳統法乘法（實測） | $\frac{n(n+1)}{2}$ | Horner 乘法（實測） | $n$ | 加法（實測） |
|-----|-------------------|--------------------|--------------------|-----|------------|
| 10 | | | | | |
| 100 | | | | | |
| 1000 | | | | | |
| 10000 | | | | | |

🤔 題目要求「**完全吻合**」。如果你的實測值和公式差了一點點（例如差 $n$ 或差 1），**不要調公式來湊**，回去檢查：

- 你的 $n$ 是「次數」還是「係數個數」？
- $k=0$ 那一項，你有沒有多乘了一次？
- 是不是有一次乘以 1 被算進去了？

這種差 1 的 bug 正是這個練習想讓你抓到的。

## 3. $n$ 翻倍的代價

🤔 先用代數算：$\dfrac{f(2n)}{f(n)}$，其中 $f(n) = \frac{n(n+1)}{2}$。化簡後，當 $n \to \infty$ 時趨近多少？

🤔 對 Horner 的 $f(n) = n$ 做同樣的事。

🤔 用程式驗證：$n = 10 \to 20$、$100 \to 200$、$1000 \to 2000$ 的比值。$n$ 小的時候比值是剛好 4 嗎？為什麼 $n$ 越大越接近 4？

## 4. 問題延伸

### 4.1 和 $O(n^3)$ 比較

🤔 做一張表，列出 $n = 10, 100, 1000$ 時，$n$、$n^2$、$n^3$ 的值。

🤔 多項式的「$n$」是什麼？高斯消去法的「$n$」是什麼？一個 $n \times n$ 的矩陣有幾個數字？

🤔 想想看：「輸入資料量」和「$n$」的關係，在這兩個問題中一樣嗎？用「每個輸入資料平均被處理了幾次」的角度來說明。

### 4.2 $O(n \log n)$ 落在哪裡？

🤔 先想數學：$\log n$ 和 $1$ 比、和 $n$ 比，哪個大？所以 $n \log n$ 和 $n$、$n^2$ 的大小關係是？

🤔 用程式印出 $n = 2^1, 2^2, \ldots, 2^{20}$ 時 $n$、$n \log_2 n$、$n^2$ 的值。

🤔 如果要「畫」三條曲線，$y$ 軸用一般刻度，$n^2$ 會讓其他兩條線變成什麼樣子？改用對數刻度（log scale）會比較好看嗎？為什麼？
