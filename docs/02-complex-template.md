## 1. 自定 `Complex` 型別

題目已經給了結構和乘法，你要補上的是其他運算。

### 1.1 先在紙上推公式

設 $z_1 = a + bi$、$z_2 = c + di$。

🤔 $z_1 + z_2$、$z_1 - z_2$ 的實部和虛部各是什麼？

🤔 題目給的乘法公式 $(ac - bd) + (ad + bc)i$，你能自己展開 $(a+bi)(c+di)$ 推出來嗎？（$i^2$ 去哪了？）

🤔 **除法是本節最難的部分**：$\dfrac{a+bi}{c+di}$ 要怎麼變成「實部 + 虛部 $i$」的形式？
提示：分子分母同乘以什麼，可以讓分母變成實數？（這就是為什麼題目同時要你寫 `conj`。）

🤔 除以 0 + 0i 會發生什麼事？你要怎麼處理？

🤔 模長 $|z| = \sqrt{a^2 + b^2}$。`abs_c` 應該回傳 `Complex` 還是 `double`？

### 1.2 隱含轉換

題目的建構子是 `Complex(double r = 0.0, double i = 0.0)`。

🤔 寫 `Complex z = 3.0;` 時，`z.re` 和 `z.im` 各是多少？為什麼可以這樣寫？

🤔 那 `Complex w = z + 1.0;` 能編譯嗎？編譯器做了什麼事？

### 1.3 先測試 `Complex` 本身

在接上 Horner 之前，先用手算得出答案的例子測試每個運算子，例如：

- $(1+2i)(3+4i) = ?$
- $\dfrac{1+2i}{3+4i} = ?$
- $i \cdot i = ?$

🤔 怎麼「驗證除法」比較聰明？（提示：如果 $q = z_1 / z_2$，那 $q \cdot z_2$ 應該等於什麼？）

🤔 印出 `Complex` 很常用到，要不要為它寫一個 `operator<<`？

## 3. 正確性驗證：$e^{1 + \frac{\pi}{4}i}$

$$E_n = \sum_{k=0}^{n} \frac{z^k}{k!}$$

🤔 $E_n$ 的係數陣列長什麼樣？每個係數是實數還是複數？（但陣列的型別要是什麼，`horner` 才能接受複數的 $z$？）

🤔 和第一題一樣：$\frac{1}{k!}$ 能不能從 $\frac{1}{(k-1)!}$ 遞推？

### 3.1 參考值

題目提示用 Euler 公式：$e^{1 + i\theta} = e(\cos\theta + i\sin\theta)$，並用 `long double` 計算。

🤔 為什麼參考值要用比 `double` 更精確的 `long double`？如果參考值本身的誤差和你要量的誤差差不多大，會有什麼問題？

🤔 `long double` 版本的 `cos`、`sin`、`exp` 怎麼呼叫？（查一下 `std::cos` 對 `long double` 的多載，或是 `cosl`。）

🤔 「誤差」要怎麼定義？實部和虛部分開看，還是用 $|E_n - \text{參考值}|$？兩種方式各有什麼優缺點？

## 4. 問題延伸

### 4.1 實係數 + 複數 $x$

🤔 **請先實際做一次**：呼叫 `horner(一個 std::vector<double>, 一個 Complex)`，編譯，**把錯誤訊息完整讀一遍**。

🤔 題目提示說「範本在推導型別時並不會做轉換」。這和第 1.2 節「`double` 可以隱含轉成 `Complex`」矛盾嗎？兩件事分別在哪個階段發生？

- 在**範本端**做點什麼？（如果範本有兩個型別參數，一個給係數、一個給 $x$，那 `result` 應該是哪種型別？回傳值呢？）

### 4.2 觀察「複可微」

設 $P(z) = z^3 - z + 2i$，$z_0 = 1 + i$，$h$ 是長度約 $10^{-6}$ 的複數。

🤔 寫程式**之前**，先預測：

1. $P'(z_0) = 3z_0^2 - 1$ 等於多少？（手算）
2. 沿實軸、虛軸、45° 方向的 $h$ 分別是什麼複數？（45° 方向且長度為 $10^{-6}$，實部虛部各是多少？）
3. 三個方向的差商 $\dfrac{P(z_0+h) - P(z_0)}{h}$，你預期會一樣嗎？

🤔 $P(z) = z^3 - z + 2i$ 的係數陣列是什麼？注意常數項是**複數**。

🤔 再對 $f(z) = \bar z$ 做同一件事。先手算：$\dfrac{\overline{z_0 + h} - \overline{z_0}}{h}$ 化簡後是什麼？它和 $z_0$ 有關嗎？和 $h$ 的**方向**有關嗎？

🤔 把三個方向的 $h$ 代進去，你預測會得到哪三個值？用程式驗證。

🤔 用一句話說明：為什麼 $P(z)$ 是「複可微」，而 $\bar z$ 不是？這和「極限與趨近方向無關」有什麼關係？

🤔 如果把 $h$ 改成 $10^{-12}$ 或 $10^{-15}$，差商會更準還是更不準？為什麼？（這和第一題的 catastrophic cancellation 是同一件事。）
