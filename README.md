## 暖身：先在紙上做一次

拿一個很小的多項式：

```math
P(x) = 2 + 3x + x^2
```

**試試看 0-1：** 如果用陣列 `a` 存係數，`a[0]`、`a[1]`、`a[2]` 分別是多少？`a[k]` 對應的是 $`x`$ 的幾次方？

<details>
<summary>答案</summary>

`a[0] = 2`、`a[1] = 3`、`a[2] = 1`。`a[k]` 是 $`x^k`$ 的係數。
注意：2 次多項式有 **3** 個係數，$`n`$ 次多項式有 $`n+1`$ 個係數。

</details>

**試試看 0-2：** 用「逐項算冪次再相加」的方法算 $`P(2)`$。把每一步的乘法、加法都寫出來，數一數總共做了幾次乘法。

<details>
<summary>答案</summary>

- 第 0 項：$`a_0 = 2`$，0 次乘法
- 第 1 項：$`3 \times 2 = 6`$，1 次乘法
- 第 2 項：$`2 \times 2 = 4`$，再 $`1 \times 4 = 4`$，2 次乘法
- 相加：$`2 + 6 + 4 = 12`$，2 次加法

共 **3 次乘法、2 次加法**。對照公式 $`\frac{n(n+1)}{2} = \frac{2 \cdot 3}{2} = 3`$。

</details>

**試試看 0-3：** 把 $`P(x)`$ 改寫成 $`2 + x(3 + x \cdot 1)`$。這個式子要**從哪一層括號開始算**？照這個順序算 $`P(2)`$，又做了幾次乘法？

<details>
<summary>答案</summary>

從**最內層**開始，也就是從最高次係數 $`a_2 = 1`$ 開始：

1. $`1 \times 2 + 3 = 5`$
2. $`5 \times 2 + 2 = 12`$

共 **2 次乘法、2 次加法**。這就是 Horner 法。

</details>

兩種算法的答案一定要相同。如果手算都對不上，寫程式只會更亂。

> 💡 **習慣**：之後每寫完一個函式，先拿這個小例子測試，確認答案是 12，再去算 $`\sin`$、$`\cos`$。

## 建議的工作節奏

1. **一次只做一件事**：先讓「傳統法算出 12」成功並編譯通過，再寫 Horner，不要一次寫完所有東西才編譯。
2. **每個函式只負責一件事**：「產生係數」、「求值」、「印出表格」各寫成獨立的函式。之後要換多項式（sin → cos → 二項式），只需要換「產生係數」那一塊。
3. **輸出要能比較**：用 `std::setprecision(17)`（在 `<iomanip>` 裡）印出足夠多位數，否則看不出浮點誤差。
4. **卡住超過 20 分鐘**：回到紙上，用 $`n=2`$ 或 $`n=3`$ 手算一次。
